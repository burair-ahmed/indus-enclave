# Estate - React JS Real Estate Website Template

Estate is a real estate landing page template designed specifically for modern property brokers, luxury real estate agencies and independent developers looking to showcase high-end residential listings. With a sleek, minimalist aesthetic and fluid Framer Motion animations. The template features a dynamic hero section, interactive statistics to build trust, a smooth sticky horizontal-scroll property gallery and user-friendly contact form.

## Installation Guide


### Next.js

1. Navigate to the `/nextjs` directory.
2. Install dependencies:

   npm install

3. Run development server:

   npm run dev
