# Indus Enclave — Web Application Frontend

Technical frontend implementation for the **Indus Enclave** real estate web platform.

---

## 🛠 Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **UI Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation & Motion:** Framer Motion
- **Icons:** Lucide React
- **Smooth Scrolling:** Lenis

---

## 📂 Key Directory Layout

- `app/` — Application routes (`/`, `/about`, `/plots`, `/villas`, `/location`, `/gallery`, `/media`, `/inquiry`, `/contact`, `/faq`)
- `components/` — Global navigation, footer, providers, and shared UI widgets
- `sections/` — Modular, animated page-level sections
- `data/` — Type-safe content definitions, milestones, video directories, and schemas
- `public/` — Static image assets, layout maps, and media

---

## ⚡ Available Scripts

In the project directory, you can run:

```bash
# Start local dev server with Turbopack (http://localhost:3000)
npm run dev

# Build optimized production bundle
npm run build

# Start production server
npm run start

# Run ESLint validation
npm run lint
```
