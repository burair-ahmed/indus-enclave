# Indus Enclave — Next.js Web Application

This is the Next.js frontend application for **Indus Enclave Housing Project**, a flagship master-planned community by **Al-Ashraf Group of Companies** on the M-9 Motorway (Exit 8 Nooriabad).

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run the local development server with Turbopack
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Runs on [http://localhost:3000](http://localhost:3000).

---

## 🛠 Key Application Modules

- **Plots Portal (`/plots`):** Sunflower Block 80 SQ.YDS (30' × 24') & 120 SQ.YDS (20' × 36') dimension diagrams, 3-year installment milestones, and real-time category surcharge calculator.
- **Villas Portal (`/villas`):** Single-family designer villas with 2-year possession timeline and 5-year installment plans.
- **Media & Progress (`/media`):** Official YouTube channel video directory with video category filtering and popup player.
- **Location & Connectivity (`/location`):** M-9 Motorway Exit 8 connectivity, drive times to Karachi/Hyderabad, and 200+ industrial landmarks.
- **Inquiry & Contact (`/contact`, `/inquiry`):** Direct booking forms and verified office contact points.
- **FAQ Portal (`/faq`):** Approvals from SBCA & SDA, pricing under 1M PKR, amenities, and overseas booking instructions.
